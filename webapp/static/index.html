Create a RapidSOS sandbox account

Fill in the form, press Preview, then Create. You'll be asked to confirm your email address; after that, press Continue and the rest runs by itself.

1 Sign in to your Google RapidSOS Account

    Signing in needs Playwright, which isn't installed on this computer. Whoever set up the app can install it by running this once, then restarting the app: 
    
      
    
      
    Or, without installing it: use a saved sign-in
    
      
      
        
    1. Open a new Chrome window, press F12, open the Network tab and tick
          Preserve log.
      2. 
        
    2. Go to andromeda.sandbox.rapidsos.com and sign in with Google.
      3. 
        
    3. Right-click the list of requests and choose Save all as HAR with content.
      4. 
        
    4. Choose that file here:
      5. 
      
    
      
      
    
      
    That file holds your live sign-in. The app reads it once and keeps only the
        session. Delete the file afterwards.
    
    
    

    
    
      About signing in
      
    The first time, a browser window opens: sign in with Google there, then come back to
        this tab. After that, signing in finishes on its own in a few seconds. A sign-in lasts
        about a day.
    
      
    The sign-in is kept on this computer only, in the app's folder, and is
        never shown on this page. It is yours: don't copy it to anyone else.
    
    
    
  
    

  
  
    
    
    Resume an existing account
    
    
    For an account that already exists, whether it was set up by hand, left
      unfinished, or created before the app was restarted. Steps that are already done are
      detected and skipped. Needs the Andromeda sign-in.

    Boundary
    
    
    
      
      
      
    
    
    
    
      
    
        
    
      
    
      
    
    
    
    
    
      
      
    
    
    
    
    
      
    Copies the boundary of the account's Active
        jurisdiction. One that is still pending is never copied. The country and state are
        filled in from that account. Nothing is written to it.

    Capabilities
    
    
    
      
      
    
    
    
    
      
    Only the capabilities are copied, not the boundary or
        the account details. Nothing is written to the account you copy from.
